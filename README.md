# Manas Gunti Portfolio

A minimalist black and white portfolio website showcasing projects, skills, experience, and education.

## Features

- Clean, minimalistic design with thin lines
- Responsive layout for all devices
- Project showcase with GitHub links
- Skills section with categorized skills
- Experience and education timelines
- Contact information
- Dark mode toggle

## Setup Instructions

1. Download all files to your local machine
2. Replace `profile-image.jpg` with your own profile photo
3. Update your resume file (replace `resume.pdf` with your actual resume)
4. Upload to your hosting provider

## File Structure

- `index.html` - Main HTML file
- `style.css` - CSS styling
- `script.js` - JavaScript functionality
- `profile-image.jpg` - Your profile photo
- `resume.pdf` - Your resume

## Customization

- To add a new project, copy a project card section and update the content
- To modify colors, update the CSS variables in the `:root` section of style.css
- To add new sections, follow the existing section structure
